No CORS needed, browser stays same-origin. Alternative: add CORS middleware to main.py allowing http://localhost:3000. (Trade-off: touches backend + open CORS; proxy keeps backend pure.)

✅Step 2 — API types + client (frontend/src/lib/). TypeScript types mirroring the API: AgentRunResponse { ok: boolean; answer?: string; error?: string; steps: Step[] } with Step { type: "tool"; cmd: string; result: { exit_code, stdout, stderr, timed_out, duration_ms } }, plus a runAgent(task) fetch function with error handling (non-2xx, network fail).

✅Step 3 — Chat state (frontend/src/lib/chat.tsx or a hook). States: idle | running | done | error. Message list: user messages + robot messages. While running: "🧠 thinking…" indicator. On completion: answer + steps.

Message list (scrollable, overflow-y-auto, no new deps needed)
Input box + Send button (Enter to send, disable while running)

Error state card (when ok: false or fetch fails)
